## Présentation

Ce dossier porte sur la documentation des violations de données à caractère personnel dans le contexte d'un groupe hôtelier.

Une violation de données personnelles peut notamment entraîner la destruction, la perte, l'altération, la divulgation non autorisée ou l'accès non autorisé à des données personnelles.

Le registre permet de conserver une trace des incidents, d'évaluer leurs conséquences et de suivre les mesures prises pour limiter les risques.

---

## Objectifs

Cette étude vise à :

- Identifier les situations pouvant constituer une violation de données personnelles.
- Décrire les incidents et leurs circonstances.
- Identifier les données concernées.
- Évaluer les conséquences potentielles pour les personnes.
- Déterminer les mesures correctives à mettre en place.
- Comprendre les obligations de documentation.
- Étudier les conditions de notification à la CNIL et, si nécessaire, aux personnes concernées.

---

## Informations documentées

Le registre peut notamment contenir les éléments suivants :

| Élément | Description |
|---|---|
| Date de l'incident | Date de détection ou de survenance |
| Nature de la violation | Perte, accès non autorisé, divulgation, destruction ou altération |
| Données concernées | Catégories de données personnelles affectées |
| Personnes concernées | Clients, salariés, prospects ou autres personnes |
| Origine de l'incident | Erreur humaine, problème technique, attaque ou autre événement |
| Conséquences possibles | Risques pour les droits et libertés des personnes |
| Mesures immédiates | Actions prises pour limiter l'incident |
| Mesures correctives | Actions destinées à éviter la répétition de l'incident |
| Notification | Analyse de la nécessité d'une notification |
| Suivi | État de traitement et clôture de l'incident |

---

## Principales étapes de gestion

La gestion d'une violation de données repose sur plusieurs étapes :

1. Détection de l'incident.
2. Qualification de la violation.
3. Identification des données concernées.
4. Évaluation des risques.
5. Mise en place de mesures d'urgence.
6. Décision concernant une éventuelle notification.
7. Documentation de l'incident.
8. Mise en œuvre d'actions correctives.
9. Suivi et clôture.
